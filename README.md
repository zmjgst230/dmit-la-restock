## 为什么你总是刷到 Out of Stock

卡住 DMIT 库存的是两个硬约束，不是它故意吊着卖。

机房硬件方面，AN5 用的是 AMD EPYC 9005 平台，新服务器的上架节奏跟不上订单速度。IP 资源方面更麻烦：Premium 和 Eyeball 每个新订单都要分配“全球可达、中国大陆首连可达”的优质 IP，CN2 GIA、CMIN2、4837 各自对应的 IP 池就那么大，用完一批要等回收或新段批复。

结果就是入门款最先见底。TINY 这一级的性价比最高，放出来几小时就没了。东京的 Pro 更极端，几乎不公开发售，只偶尔通过 Telegram 频道放几台。香港 Pro 历史上最短的一次补货不到三个小时售完。

## Pro、EB、T1 按运营商怎么选

**Pro（Premium，CN2 GIA）。** 三网回程走 CN2 GIA，电信去程直连，联通去程走 AS4837，移动去程经香港移动。电信和联通用户的体验最完整，企业建站、对稳定性要求高的业务选这条。第三方测评口径下，晚高峰和白天差别不大，没有明显掉速。

**EB（Eyeball，CMIN2）。** 以 CMIN2 为主的移动优化线路，移动宽带用户在这条线上的表现比 Pro 更好，同价位给的流量也更多。AS3 平台上 Pro 和 EB 同配置同价格，EB 的流量高一截，移动用户没有理由选 Pro。

**联通用户**两条线差别不大，哪个有货、哪个便宜就选哪个。

**T1（Tier 1，国际线路）。** 只优化亚美、欧美、亚欧之间的路由，不针对中国大陆做优化，价格最低，而且常年有货不用蹲。这里有个容易被忽略的限制：T1 不保证 IP 全球可达，中国、俄罗斯等敏感地区首连不保证，需要额外买 `IP Guarantee+` 插件才行。如果你的用途对 IP 可达性敏感，别为了省几美元选 T1。

拿不准线路质量，可以用官方 Looking Glass 自己测：Pro 的测试 IP 是 `45.90.213.1`，EB 系列是 `154.17.226.4`（另有 IPv6 `2605:52c0:1:3:2c2a:59ff:fe05:65c2`）。用自己的宽带 ping 一遍，比看任何测评都准。

## 真实成本：AN5 时代门槛抬了多少

把季付折算成年，账就清楚了。

AN5.Pro.TINY 季付 $37.99，一年四个季度是 $151.96，月均约 $12.66。AS3.Pro.TINY 月付 $10.90，一年 $130.80。同样是 1 核 2G、20G 硬盘、1TB 流量，AN5 比 AS3 每年贵约 $21，差价来自 CPU 代际（EPYC 9005 对 7003）。

入门门槛的变化更明显。AN4 时代“几十美元年付拿下 CN2 GIA”的方案已经随着平台下架消失，AN5 的 Pro 和 EB 最低就是季付 $37.99 起步，等于年付 $150 左右。现在还想用一百美元出头跑一年，得看 AS3 平台：Pro TINY 月付 $10.90，或者 T1 WEE 年付 $36.9。

T1 内部也有代际差：AS3.T1.WEE 年付约 $36.9 是 1 核 1G，AN5.T1.V2C2G 月付 $14.90、年付约 $178.8 是 2 核 2G 加 5TB 流量。配置翻倍，价格翻近五倍，看你需要的是“能跑”还是“跑得宽裕”。

优惠码这块要克制。DMIT 的折扣码只对新客户生效，不能叠加，多数限定年付或非月付周期。社区里流传过 EB 系列的 20% 循环折扣（TINY 以上）、LAX T1 年付 20% 终身折扣，这类码会过期也会被官方撤回，结账页试一次，不生效就按原价买。为凑一个不确定的折扣改买自己用不上的计费周期，不划算。

另外提醒一句：如果你搜到“sPro 停运补偿折扣”（Pro 20%、EB 25%、T1 30%），那个活动窗口是 2025 年 11 月 1 日到 2026 年 4 月 30 日，已经关闭，别按那个折扣做预算。

## 下单前必须知道的几条硬限制

**25 端口封闭。** 对外 SMTP 不通，自建邮件服务器这条路直接堵死。

**流媒体解锁不稳。** 洛杉矶 IP 在 Netflix、Disney+ 上的解锁率不稳定，有时候完全解不了。多数人拿它当线路机，另外配一台专门解锁的落地机。

**ChatGPT 访问受限概率偏高。** 洛杉矶 IP 被 OpenAI 限制的情况不少，不保证每个 IP 都能直接访问。

**退款政策。** 3 天内且流量使用不超过 30GB 可以全额退，扣支付网关交易费；30 天内按剩余价值部分退；同一系列已经退过 3 次、遭遇 DDoS、以网络不佳或 IP 地理位置为由的，不予退款。退款选择退到账户余额可以免掉手续费。下单后第一时间测线路，不满意趁 3 天内处理。

**换 IP。** 没有 `IP Care+` 的月付和年付用户都是每 15 天可以免费换一次；买了 `IP Care+` 的每 7 天一次。IP 被确认封锁后提交工单处理。

**支付方式。** 支付宝、微信支付、PayPal 都支持。有测评提到支付宝流程最顺，不需要国际信用卡。
